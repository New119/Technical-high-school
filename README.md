# ルール

ルール
ターン制
LP(4000)の削り合いor確率による即死が勝敗の条件
メインカードとサポートカードがある
メインカードは以下
小    4枚    4%　 (100LPを削る)
中    2枚    15%　(800LPを削る)
大    1枚    50%　(相手のライフを90％削る)
毎ターン終了時死ぬか生きるかの抽選をし、その確率は使ったメインカードに応じた確率で死ぬ
1ターン終わる毎にサポートカードを使うためのエネルギーを1ポイント獲得する。これを「マナ」と呼ぶ。
ターンの終了時に使ったカードの効果の処理が行われる。
毎ターンサポートカードはリロールされ、基準値は5枚。
サポートカードを規定枚数破棄することでウルトを使える。使用後のターンは破棄した枚数分配られるサポートカードが減る。
メインカードを両プレイヤーともに使い果たした場合、その時点でLPが多いプレイヤーの勝利とする。
