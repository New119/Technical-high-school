# ゲームロジック初期実装の範囲

このPRは既存READMEのルールを変更しないための **Rubyの基礎部品** だけを追加します。Web画面や実際に遊べる対戦はまだありません。

## 実装済み

- 初期LP: 4,000
- メインカードの初期枚数: 小4・中2・大1
- 即死確率の定義: 4%・15%・50%（**抽選処理はまだない**）
- 小: 100LP、中: 800LP、大: 相手の現在LPの90%（大は端数を丸めない有理数で計算）
- 使用したメインカードの枚数を減らす独立した操作
- 1ターン終了後のマナ +1 を表す独立した操作
- サポートカードの基準枚数 5 を定数として定義
- 整数ダメージを受けたときのLP減少処理

## 未実装・未決定（推測で追加しない）

- ターン進行・先攻後攻・1ターンの使用可能枚数
- 即死抽選の対象者、抽選タイミングや複数カードの確率の合算方法
- ターン末のカード効果・即死判定・LP決着の優先順位
- 大カードの小数点の丸め方（そのため大カードのダメージは自動的にLPへ適用しない）
- マナの初期値・所持上限・サポートカード一覧とマナ消費量
- サポートカードのリロール・ウルトの発動条件と効果
- 両者のカード切れ・LP同点を含む勝敗判定
- Webアプリのフレームワーク、画面、CPU、オンライン対戦

## ローカルテスト

RubyとMinitestが利用できる環境で、リポジトリ直下から実行します。

```sh
ruby -Ilib test/card_game_test.rb
```

この初期PRでRuby・RailsのバージョンやWebフレームワークを決めてはいません。技術構成の選定は Issue #8 で行います。ゲームルールの未定義部分は Issue #5 に記録します。
